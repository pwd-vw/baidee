# BaiDee decisions

## 2026-09-30

- Phase 1 begins with one row (`rA`) and one camera node. The layout contract remains extensible so additional rows and zones are configuration changes.
- Network distance is not a product blocker. The deployment can be adjusted as the site changes; software keeps store-and-forward behavior at the edge.
- Shade cloth is an adjustable operating condition, not an architectural constraint. Image quality checks and calibration remain configurable.
- Experienced farmers will review labels and have granted permission for commercial use of the collected data.
- The initial commercial audience is farmers presented with a productized BaiDee solution.
